# Root

Public documentation workspace.

This repository starts intentionally small. Another AI agent is expected to add
the first real docs here.

## Rules

1. Keep this repository public-safe.
2. Do not commit secrets, raw personal exports, private logs, device serials, or
   account tokens.
3. Put durable public docs in `docs/`.
4. Use local-only ignored folders for scratch or private material.

## Start Here

- `docs/README.md` is the first docs landing page.
- `AGENTS.md` contains working rules for agents in this repo.
- `docs/tools/blog-website-maker.md` is the first reusable public tool
  playbook.
- `scripts/create_blog_site.py` scaffolds a small Astro Markdown blog.
