# Agent Instructions

This is a public repository named `root`.

## Working Rules

- Treat all committed content as public.
- Do not add secrets, raw personal data, private Workflow Manager logs, device
  identifiers, access tokens, or unredacted account details.
- Prefer concise Markdown docs in `docs/`.
- Keep implementation minimal until the project direction is clear.
- If private source material is needed, summarize or redact it before committing.
- Check `git status -sb` before and after changes.

## Current Purpose

This repo is a clean public project folder for another AI agent to populate with
documentation.
